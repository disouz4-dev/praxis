Спілкування завжди було найпотужнішим інструментом людства. Проте мова залишається однією з найбільших перешкод між людьми, культурами та ідеями.

**Praxis** створено, щоб це змінити.

Ідея проста: дозволити двом людям вести природну розмову, кожному своєю мовою, поки інший чує все рідною мовою — в режимі реального часу.

---

## Бачення

Створити платформу голосового перекладу в реальному часі, що забезпечує природне спілкування між людьми будь-де у світі, зберігаючи контекст, емоції та плавність.

## Місія

Усунути мовні бар'єри, щоб ідеї, знання та стосунки перетинали кордони без мовних перешкод.

## Принципи

- Технологія має зближувати людей.
- Кожен голос заслуговує бути почутим.
- Мова не повинна обмежувати зв'язки.
- Переклад має бути настільки природним, що зникає з розмови.
- Повідомлення може досягти будь-кого будь-якою мовою.

---

## Як це працює

Praxis створює **віртуальний мікрофон** в операційній системі. Ви говорите своєю мовою; голос виходить уже перекладеним — готовий до вибору в Discord, WhatsApp, Google Meet, OBS або будь-якому іншому застосунку.

```
Справжній мікрофон  →  VAD  →  Whisper ASR  →  Argos Translate  →  Piper TTS
                                                                          ↓
                                                        Віртуальний sink (Praxis_Out)
                                                                          ↓
                                                   Praxis_Microfone  ←  Discord / Meet / OBS
```

Все працює **100% локально** — без інтернету, без хмари, нічого не залишає ваш комп'ютер.

## Режими активації

| Режим | Опис |
|-------|------|
| **Авто VAD** | Silero VAD виявляє розмову та активується автоматично |
| **Gate поріг** | Активується лише вище порогового значення гучності |
| **Push-to-Talk** | Утримуйте кнопку (клавіатура або миша) для передачі |

## Встановлення

```bash
git clone https://github.com/disouz4-dev/praxis.git
cd praxis
chmod +x install.sh && ./install.sh
```

Інсталятор створює ізольоване віртуальне середовище, встановлює всі залежності (PyTorch, Whisper, Argos, Piper) і робить команду `praxis` глобально доступною.

### Вимоги

- Linux з PulseAudio або PipeWire
- Python 3.10+
- `pulseaudio-utils` (`pactl`, `parec`)
- GPU NVIDIA з CUDA (рекомендується) або CPU

---

## Використання

```bash
praxis
```

У вікні налаштувань оберіть:
1. **Режим** активації (VAD / Gate / PTT)
2. **Мікрофон** введення
3. **Вихідну та цільову мову**
4. **Вихідний голос** (завантажте додаткові голоси кнопкою ⬇ Завантажити)
5. Натисніть **✦ Запуск**

У застосунку для дзвінків оберіть **Praxis_Microfone** як пристрій введення аудіо.

## Технічний конвеєр

| Етап | Інструмент | Деталі |
|------|-----------|--------|
| Сегментація мовлення | **Silero VAD** | Розрізання за тишею (200мс) або макс. тривалістю (4с) |
| Транскрипція | **faster-whisper** | Модель `small` за замовчуванням; GPU int8_float16 / CPU int8 |
| Переклад | **Argos Translate** | 100% офлайн; завантажує мовні пари при першому використанні |
| Синтез мовлення | **Piper TTS** | Легкі `.onnx` моделі; паралельний синтез по реченнях |
| Вивід аудіо | **pacat + PulseAudio** | Пряма ін'єкція у віртуальний sink |

## Клонування голосу (OmniVoice)

Вкладка **"Клонувати мій голос"** дозволяє клонувати будь-який голос за секунди — просто запишіть або імпортуйте аудіокліп 5–15 секунд. Без навчання, без очікування.

### Як використовувати

1. Відкрийте вкладку **🎙 Клонувати мій голос**
2. Введіть назву профілю (напр. `Diego`)
3. **Варіант А — Запис:** натисніть на мікрофон і прочитайте короткий загальний текст
   **Варіант Б — Імпорт:** натисніть "Імпортувати аудіо" і виберіть будь-який WAV/MP3/OGG/OPUS/M4A/FLAC/AAC (включаючи голосові повідомлення WhatsApp)
4. Натисніть **Тест** щоб почути клонований голос
5. Натисніть **Використати** щоб активувати його як вивід за замовчуванням

> Еталонне аудіо автоматично обрізається до 15 секунд для найкращої якості клонування.

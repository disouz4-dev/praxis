संचार हमेशा से मानवता का सबसे शक्तिशाली उपकरण रहा है। फिर भी भाषा लोगों, संस्कृतियों और विचारों के बीच सबसे बड़ी बाधाओं में से एक बनी हुई है।

**Praxis** इसे बदलने के लिए बनाया गया है।

विचार सरल है: दो लोगों को अपनी-अपनी भाषा में स्वाभाविक बातचीत करने दें, जबकि दूसरा व्यक्ति सब कुछ अपनी मातृभाषा में सुने — वास्तविक समय में।

---

## दृष्टिकोण

एक रियल-टाइम वॉइस ट्रांसलेशन प्लेटफॉर्म बनाना जो दुनिया में कहीं भी लोगों के बीच प्राकृतिक बातचीत को सक्षम करे, संदर्भ, भावना और प्रवाहमयता को बनाए रखते हुए।

## मिशन

भाषाई बाधाओं को दूर करना ताकि विचार, ज्ञान और रिश्ते भाषा की बाधा के बिना सीमाओं को पार कर सकें।

## सिद्धांत

- तकनीक लोगों को करीब लाना चाहिए।
- हर आवाज को समझे जाने का अधिकार है।
- भाषा संबंधों को सीमित नहीं करनी चाहिए।
- अनुवाद इतना स्वाभाविक होना चाहिए कि वह बातचीत से गायब हो जाए।
- एक संदेश किसी भी भाषा में किसी तक पहुंच सकता है।

---

## यह कैसे काम करता है

Praxis ऑपरेटिंग सिस्टम में एक **वर्चुअल माइक्रोफोन** बनाता है। आप अपनी भाषा में बोलते हैं; आवाज पहले से अनुवादित होकर निकलती है — Discord, WhatsApp, Google Meet, OBS या किसी भी अन्य ऐप में चुनने के लिए तैयार।

```
असली माइक्रोफोन  →  VAD  →  Whisper ASR  →  Argos Translate  →  Piper TTS
                                                                        ↓
                                                      वर्चुअल sink (Praxis_Out)
                                                                        ↓
                                               Praxis_Microfone  ←  Discord / Meet / OBS
```

सब कुछ **100% स्थानीय** रूप से चलता है — कोई इंटरनेट नहीं, कोई क्लाउड नहीं, कुछ भी आपकी मशीन नहीं छोड़ता।

## इंस्टॉलेशन

```bash
git clone https://github.com/disouz4-dev/praxis.git
cd praxis
chmod +x install.sh && ./install.sh
```

इंस्टॉलर एक अलग वर्चुअल वातावरण बनाता है, सभी निर्भरताएं (PyTorch, Whisper, Argos, Piper) इंस्टॉल करता है, और `praxis` कमांड को वैश्विक रूप से उपलब्ध कराता है।

### आवश्यकताएं

- PulseAudio या PipeWire के साथ Linux
- Python 3.10+
- `pulseaudio-utils` (`pactl`, `parec`)
- CUDA के साथ NVIDIA GPU (अनुशंसित) या CPU

---

## उपयोग

```bash
praxis
```

कॉन्फ़िगरेशन विंडो में, चुनें:
1. **सक्रियण मोड** (VAD / Gate / PTT)
2. **इनपुट माइक्रोफोन**
3. **स्रोत और लक्ष्य भाषा**
4. **आउटपुट वॉइस** (⬇ डाउनलोड बटन से अतिरिक्त आवाजें डाउनलोड करें)
5. **✦ शुरू करें** पर क्लिक करें

अपने कॉल ऐप में, ऑडियो इनपुट डिवाइस के रूप में **Praxis_Microfone** चुनें।

| चरण | टूल | विवरण |
|-----|-----|-------|
| स्पीच सेगमेंटेशन | **Silero VAD** | चुप्पी (200ms) या अधिकतम अवधि (4s) पर कट |
| ट्रांसक्रिप्शन | **faster-whisper** | डिफ़ॉल्ट `small` मॉडल; GPU int8_float16 / CPU int8 |

| वॉइस सिंथेसिस | **Piper TTS** | हल्के `.onnx` मॉडल; प्रति वाक्य समानांतर सिंथेसिस |
| ऑडियो आउटपुट | **pacat + PulseAudio** | वर्चुअल sink में सीधे इंजेक्शन |

## वॉइस क्लोनिंग (OmniVoice)

**"मेरी आवाज क्लोन करें"** टैब आपको सेकंडों में किसी भी आवाज को क्लोन करने देता है — बस 5–15 सेकंड का ऑडियो क्लिप रिकॉर्ड करें या आयात करें। कोई प्रशिक्षण नहीं, कोई प्रतीक्षा नहीं।

### कैसे उपयोग करें

1. **🎙 मेरी आवाज क्लोन करें** टैब खोलें
2. प्रोफ़ाइल के लिए एक नाम दर्ज करें (जैसे `Diego`)
3. **विकल्प A — रिकॉर्ड:** माइक्रोफोन बटन पर क्लिक करें और एक छोटा सामान्य टेक्स्ट पढ़ें
   **विकल्प B — आयात:** "ऑडियो आयात करें" पर क्लिक करें और कोई भी WAV/MP3/OGG/OPUS/M4A/FLAC/AAC फ़ाइल चुनें (WhatsApp वॉइस मैसेज सहित)
4. क्लोन की गई आवाज सुनने के लिए **टेस्ट** पर क्लिक करें
5. इसे डिफ़ॉल्ट आउटपुट के रूप में सक्रिय करने के लिए **उपयोग करें** पर क्लिक करें

> संदर्भ ऑडियो सर्वोत्तम क्लोनिंग गुणवत्ता के लिए स्वचालित रूप से 15 सेकंड तक काटा जाता है।

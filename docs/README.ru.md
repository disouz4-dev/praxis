Общение всегда было самым мощным инструментом человечества. Однако язык по-прежнему остаётся одним из главных барьеров между людьми, культурами и идеями.

**Praxis** создан, чтобы изменить это.

Идея проста: позволить двум людям вести естественный разговор, каждый на своём языке, пока другой слышит всё на родном языке — в реальном времени.

Представьте: бразилец говорит по-португальски, а американец слышит каждое слово по-английски. Через мгновение американец отвечает по-английски, и бразилец слышит ответ по-португальски. Никаких пауз на перевод. Просто разговор.

---

## Видение

Создать платформу голосового перевода в реальном времени, обеспечивающую естественное общение между людьми в любой точке мира с сохранением контекста, эмоций и беглости речи.

## Миссия

Устранить языковые барьеры, чтобы идеи, знания и отношения пересекали границы без языковых ограничений.

## Принципы

- Технология должна сближать людей.
- Каждый голос заслуживает быть понятым.
- Язык не должен ограничивать связи.
- Перевод должен быть настолько естественным, что исчезает из разговора.
- Сообщение может достичь любого человека на любом языке.

---

## Как это работает

Praxis создаёт **виртуальный микрофон** в операционной системе. Вы говорите на своём языке; голос выходит уже переведённым — готов к выбору в Discord, WhatsApp, Google Meet, OBS или любом другом приложении.

```
Реальный микрофон  →  VAD  →  Whisper ASR  →  Argos Translate  →  Piper TTS
                                                                        ↓
                                                          Виртуальный sink (Praxis_Out)
                                                                        ↓
                                                     Praxis_Microfone  ←  Discord / Meet / OBS
```

Всё работает **100% локально** — никакого интернета, никакого облака, ничего не покидает ваш компьютер.

---

## Режимы активации

| Режим | Описание |
|-------|----------|
| **Авто VAD** | Silero VAD определяет, когда вы говорите, и активируется автоматически |
| **Gate threshold** | Активируется только выше порогового значения громкости |
| **Push-to-Talk** | Удерживайте кнопку (клавиатуру или мышь) для передачи |

## Установка

```bash
git clone https://github.com/disouz4-dev/praxis.git
cd praxis
chmod +x install.sh && ./install.sh
```

Установщик создаёт изолированную виртуальную среду, устанавливает все зависимости (PyTorch, Whisper, Argos, Piper) и делает команду `praxis` доступной глобально.

### Требования

- Linux с PulseAudio или PipeWire
- Python 3.10+
- `pulseaudio-utils` (`pactl`, `parec`)
- GPU NVIDIA с CUDA (рекомендуется) или CPU

---

## Использование

```bash
praxis
```

В окне настроек выберите:
1. **Режим** активации (VAD / Gate / PTT)
2. **Микрофон** для ввода
3. **Исходный и целевой язык**
4. **Выходной голос** (загрузите дополнительные голоса кнопкой ⬇ Скачать)
5. Нажмите **✦ Запуск**

В приложении для звонков выберите **Praxis_Microfone** как устройство ввода аудио.

---

## Технический конвейер

| Этап | Инструмент | Детали |
|------|-----------|--------|
| Сегментация речи | **Silero VAD** | Разрез по тишине (200мс) или макс. длительности (4с) |
| Транскрипция | **faster-whisper** | Модель `small` по умолчанию; GPU int8_float16 / CPU int8 |
| Перевод | **Argos Translate** | 100% офлайн; загружает языковые пары при первом использовании |
| Синтез речи | **Piper TTS** | Лёгкие `.onnx` модели; синтез по предложениям параллельно |
| Вывод аудио | **pacat + PulseAudio** | Прямая инъекция в виртуальный sink |

## Клонирование голоса (OmniVoice)

Вкладка **"Клонировать мой голос"** позволяет клонировать любой голос за секунды — просто запишите или импортируйте аудиоклип длиной 5–15 секунд. Никакого обучения, никакого ожидания.

### Как использовать

1. Откройте вкладку **🎙 Клонировать мой голос**
2. Введите имя профиля (напр. `Diego`)
3. **Вариант А — Запись:** нажмите на микрофон и прочитайте короткий общий текст
   **Вариант Б — Импорт:** нажмите "Импортировать аудио" и выберите любой WAV/MP3/OGG/OPUS/M4A/FLAC/AAC (включая голосовые сообщения WhatsApp)
4. Нажмите **Тест** чтобы услышать клонированный голос
5. Нажмите **Использовать** чтобы активировать его как выход по умолчанию

> Референсное аудио автоматически обрезается до 15 секунд для лучшего качества клонирования.

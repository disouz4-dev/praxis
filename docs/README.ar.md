كان التواصل دائمًا أقوى أداة للبشرية. ومع ذلك، لا تزال اللغة من أكبر الحواجز بين الناس والثقافات والأفكار.

**Praxis** بُني لتغيير ذلك.

الفكرة بسيطة: السماح لشخصين بإجراء محادثة طبيعية، كل منهما بلغته الخاصة، بينما يسمع الآخر كل شيء بلغته الأم — في الوقت الفعلي.

---

## الرؤية

بناء منصة ترجمة صوتية في الوقت الفعلي تتيح محادثات طبيعية بين الناس في أي مكان في العالم، مع الحفاظ على السياق والعاطفة والطلاقة.

## الرسالة

القضاء على الحواجز اللغوية حتى تتمكن الأفكار والمعرفة والعلاقات من عبور الحدود دون أن تكون اللغة عقبة.

## المبادئ

- يجب أن تُقرّب التكنولوجيا الناس من بعضهم.
- كل صوت يستحق أن يُفهم.
- يجب ألا تُقيّد اللغة الاتصالات.
- يجب أن تكون الترجمة طبيعية لدرجة أنها تختفي من المحادثة.
- يمكن لرسالة واحدة الوصول إلى أي شخص بأي لغة.

---

## كيف يعمل

ينشئ Praxis **ميكروفونًا افتراضيًا** في نظام التشغيل. تتكلم بلغتك؛ يخرج الصوت مترجمًا بالفعل — جاهزًا للاختيار في Discord أو WhatsApp أو Google Meet أو OBS أو أي تطبيق آخر.

```
ميكروفون حقيقي  →  VAD  →  Whisper ASR  →  Argos Translate  →  Piper TTS
                                                                       ↓
                                                       مخرج افتراضي (Praxis_Out)
                                                                       ↓
                                                Praxis_Microfone  ←  Discord / Meet / OBS
```

كل شيء يعمل **100% محليًا** — لا إنترنت، لا سحابة، لا شيء يغادر جهازك.

## التثبيت

```bash
git clone https://github.com/disouz4-dev/praxis.git
cd praxis
chmod +x install.sh && ./install.sh
```

يُنشئ المثبّت بيئة افتراضية معزولة، ويثبّت جميع التبعيات (PyTorch, Whisper, Argos, Piper)، ويجعل أمر `praxis` متاحًا عالميًا.

### المتطلبات

- Linux مع PulseAudio أو PipeWire
- Python 3.10+
- `pulseaudio-utils` (`pactl`، `parec`)
- GPU NVIDIA مع CUDA (موصى به) أو CPU

---

## الاستخدام

```bash
praxis
```

في نافذة الإعداد، اختر:
1. **وضع** التنشيط (VAD / Gate / PTT)
2. **ميكروفون** الإدخال
3. **اللغة** المصدر والهدف
4. **الصوت** المخرج (حمّل أصواتًا إضافية بزر ⬇ تحميل)
5. انقر على **✦ ابدأ**

في تطبيق المكالمة، اختر **Praxis_Microfone** كجهاز إدخال صوتي.

## خط أنابيب تقني

| المرحلة | الأداة | التفاصيل |
|---------|--------|---------|
| تجزئة الكلام | **Silero VAD** | قطع على الصمت (200ms) أو المدة القصوى (4s) |
| النسخ | **faster-whisper** | نموذج `small` افتراضيًا؛ GPU int8_float16 / CPU int8 |
| الترجمة | **Argos Translate** | 100% بدون إنترنت؛ يُنزّل أزواج اللغات عند الاستخدام الأول |
| تركيب الكلام | **Piper TTS** | نماذج `.onnx` خفيفة؛ تركيب متوازٍ بالجملة |
| إخراج الصوت | **pacat + PulseAudio** | حقن مباشر في المخرج الافتراضي |

## استنساخ الصوت (OmniVoice)

تتيح لك علامة تبويب **"استنسخ صوتي"** استنساخ أي صوت في ثوانٍ — فقط سجّل أو استورد مقطعًا صوتيًا مدته 5–15 ثانية. لا تدريب، لا انتظار.

### كيفية الاستخدام

1. افتح علامة التبويب **🎙 استنسخ صوتي**
2. أدخل اسمًا للملف الشخصي (مثلًا `Diego`)
3. **الخيار أ — تسجيل:** انقر على زر الميكروفون واقرأ نصًا عامًا قصيرًا
   **الخيار ب — استيراد:** انقر على "استيراد صوت" واختر أي ملف WAV/MP3/OGG/OPUS/M4A/FLAC/AAC (بما في ذلك رسائل WhatsApp الصوتية)
4. انقر على **اختبار** للاستماع إلى الصوت المُستنسخ
5. انقر على **استخدام** لتفعيله كإخراج افتراضي

> يُقلَّص الصوت المرجعي تلقائيًا إلى 15 ثانية لأفضل جودة استنساخ.
